El dashboard no pudo leer data/datos.json mediante fetch(). Esto casi siempre ocurre por uno de estos motivos:

• Abriste index.html con doble clic (protocolo file://), lo cual bloquea fetch() por política del navegador. Solución: publica en GitHub Pages o corre un servidor local (ver README.md).

• El archivo data/datos.json no existe en esa ruta o el JSON está corrupto.
